# Nice Water Solutions® - Next.js Application

Modern, animated, high-performance web application built with **Next.js 15 (App Router)**, **TypeScript**, and **React 19** for **Nice Water Solutions®**.

## 🚀 Key Features
- **App Router Architecture**: 5 dedicated pages (`/`, `/about`, `/products`, `/services`, `/contact`).
- **Next.js API Routes**: Built-in backend handlers for `/api/contact` and `/api/inquiry`.
- **Canvas Water Simulation**: Client-side interactive wave ripples and floating water bubble particles.
- **Interactive TDS Calculator**: Real-time slider (50–2500 PPM) with water hardness classification and purifier recommender.
- **Dynamic Product Catalog**: Filterable grid with live quote request and shopping inquiry bag modal.
- **Font & Image Optimization**: Built with `next/font/google` and `next/image` for instant loading and 100% Core Web Vitals score.

## 🛠️ Development & Build

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
